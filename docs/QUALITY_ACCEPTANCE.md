# 模糊、曝光与筛选前后 SfM 验收

## 1. 范围与先行固定的条件

2026-11-03，本轮只使用本机 Kitchen 数据，不使用 Dozer 标签调参或评分。
不修改应用默认阈值，不自动替用户取消图片选择，不改变原始数据。
本文件先于实际重建结果建立，运行前将协议、输入 SHA-256、阈值及代码哈希写入新实验目录。

分两类证据，禁止相互替代：

1. **检测响应实验**：真实照片副本上的多等级单因素变换，测分数、告警率及交叉告警。
   生成过程已知不等于真实相机质量人工真值，不将响应率称为真实准确率。
2. **SfM 对照**：冻结图片和筛选规则，比较原始输入与筛选输入，记录注册覆盖、内部残差、
   位姿参考一致性、耗时和失败。检测告警是否正确仍需独立人工质量标注。

## 2. 模糊、曝光依据与边界

当前生产实现为 `recon_workbench/image_quality.py`：

- 先按 EXIF 校正方向，转 8 位灰度，等比例缩小到最长边不超过 512；不放大。
- 清晰度是内部像素的四邻域离散 Laplacian 响应方差，低于 60 提示疑似模糊。
  这是边缘变化指标；少纹理、曝光、噪声和分析尺度也会影响它，不等于专门的模糊概率。
- 灰度均值低于 40，或灰度 <=20 的像素比例 >=0.6，提示疑似欠曝。
- 灰度均值高于 215，或灰度 >=235 的像素比例 >=0.6，提示疑似过曝。
  暗场、白墙、局部高光和混合照明可能不满足这种全图规则，不能据此认定照片不可用。
- 原图未经人工质量标注，不自动作为“正常负例”；变体也不自动变成人工“问题正例”。

依据：

- OpenCV Laplace Operator：<https://docs.opencv.org/4.x/d5/db5/tutorial_laplace_operator.html>
  仅支持离散二阶导数的含义，不为本项目的阈值 60 背书。
- COLMAP 输出位姿：<https://colmap.github.io/format.html>
- Nerfstudio 坐标约定：<https://docs.nerf.studio/quickstart/data_conventions.html>

这些是计算定义与数据格式依据，不是“默认阈值普适有效”的证据。

## 3. 检测响应实验

从 Kitchen 的 `transforms.json` 顺序均匀抽取 24 个源帧，源帧及其所有变体不得跨 split。
前 12 组记 calibration，后 12 组记 validation；本轮两个 split 均不做阈值搜索。
同一场景仍有相关性，因此不是跨场景独立验证。

每源帧保留原始字节，另生成同尺寸 PNG：

- Gaussian blur：半径 0.75、2、6 原图像素；
- 亮度倍率：0.18、0.5、0.8、1.25、1.8、3.0。

总计 240 张。每次只主动变换一个因素，记录亮度变化对模糊告警的交叉影响。
对生成等级报告响应率；未标注原图仅报告告警率，不报告误报率。
额外用灰色平面、黑白平面及加噪控制说明纹理/曝光/噪声的混淆，不计入相机质量准确率。
人工标注模板保持未复核状态；后续固定人工标签后才能算各类 precision/recall。

## 4. SfM 对照

从同一源序列均匀取 60 张原图覆盖拍摄范围，不使用发布位姿来初始化重建。
选择至少 3 个可用视图；若保留不足、注册失败或模型分裂，按失败报告，不补选图片掩盖结果。

固定四组：

| 组 | 输入 |
|---|---|
| original | 60 张原图 |
| original_filtered | 从 original 排除疑似模糊/欠曝/过曝告警图片 |
| augmented | original + 15 张已知退化副本，最终文件中退化副本占 20% |
| augmented_filtered | 对 augmented 使用同一告警规则筛选，原图也不特殊豁免 |

15 张变体来源不同：5 张半径 6 模糊、5 张亮度 0.18、5 张亮度 3.0。
不按变体已知身份直接删除；只依据已冻结的告警规则。
不启用 dHash/pHash 筛选，从而隔离本轮质量告警的影响。
筛选只是实验中的阈值消融策略，不是新增产品自动排除行为。

每组独立运行 3 次，新数据库、新模型；轮换四组执行次序，串行运行，不跨次复用特征。
参数固定 CPU 4 线程、OPENCV 独立相机、最大边长 1000、SIFT 上限 4096、exhaustive 匹配。
每次重建设置 3600 秒超时，超时保留为失败；不缩小输入或降低参数补跑来替代该次结果。
记录 COLMAP/依赖/代码版本、每次命令、完整日志、原图/变体注册清单、所有子模型。
不要求三次输出点数完全一致；报告中位数与范围，不把点数当精度。

## 5. 评价口径

- **覆盖**：按冻结的 60 张原图为共同分母，分别统计被筛除、已注册和未注册。
  除各组自身注册率外，必须保留这个共同分母，避免删图后分母变小制造改善。
- **内部一致性**：重投影误差、轨迹长度、观测数和子模型数量；不视作真实几何精度。
- **参考位姿一致性**：发布的 Kitchen 位姿是已处理数据的参考，不是测量级真值。
  从所有组预计保留的原图中预先固定 8 张 alignment 锚点，其他共同保留原图用于 evaluation。
  用锚点拟合正尺度、无反射的 Sim(3)，仅在 evaluation 帧上评估位置残差与旋转差。
  COLMAP world-to-camera 转 camera-to-world；Nerfstudio OpenGL 相机转为 OpenCV 约定。
  锚点缺失或退化时报告不可比较，不悄悄更换锚点。另报告未注册 evaluation 帧，防止幸存者偏差。
- **耗时**：同机重复运行的墙钟时间，包含完整 SfM 子进程；不含检测/人工复核。
- **缺失的几何真值**：不计算或编造点云精度、完整度、Chamfer/F-score，不声称质量普遍提升。

本轮完成标准是实验可追溯、检测响应有记录、对照按冻结规则执行且负面结果不省略，
不是强求筛选有收益。真实照片的人工质量分类准确率、外部场景泛化和点云几何精度仍须后续补齐。
