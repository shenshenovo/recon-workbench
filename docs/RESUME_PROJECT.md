# 科研实习简历：辅助项目表述

## 可放入简历的版本

**Recon Workbench：多路线三维重建工作台｜课程综合设计**

**个人职责：重建主线搭建、算法工具集成与实验验证**

技术：Python、COLMAP、OpenMVS、3D Gaussian Splatting（Brush）

- 搭建多视图照片到三维结果的统一处理主线，集成 COLMAP SfM、OpenMVS 稠密重建与 Brush 3DGS 训练，封装数据准备、参数适配、阶段调度及日志记录，支持复用 SfM 结果进入后续路线。
- 使用 ETH3D 与 Nerfstudio dozer 场景验证重建流程，定位鱼眼图像缺少焦距先验导致几何验证失败的问题，补充相机内参传递与校验，在 dozer 的 50 张照片上完成 50/50 相机注册。

项目作为科研实习简历的辅助经历，建议控制为以上两条，优先给主要科研经历、论文复现或研究成果留出篇幅。前端不列入这段个人贡献；团队成员的工作只按实际分工描述。

## 面试时可核对的事实

- 主线和调用边界：`recon_workbench/pipeline.py` 调度 `reconstruct.py`、`densify.py`、`train_3dgs.py`，3DGS 数据准备在 `prepare_brush.py`。本项目调用第三方底层算法，不表述为自研 SfM、MVS 或 3DGS 算法。
- 工程验证：当前 65 项自动化测试通过；测试数量不代表 65 个真实重建场景。图片质量检查是可解释的启发式提示，没有经过检测准确率标定。
- 鱼眼排查：原任务有描述子匹配，但几何验证图像对为 0；补充发布数据的相机内参并共享内参后完整重跑，未导入发布相机位姿或三维点。
- dozer 单次复验：50 张输入、50 张注册、21995 个稀疏点；原任务快照与测试设置见 [数据集测试计划第 8 节](DATASET_TEST_PLAN.md#8-鱼眼焦距先验与-dozer-50-张复验)。该结果不证明几何真值精度、算法创新或工作台容量上限。
- ETH3D 的 SfM、OpenMVS 和 Brush 真实运行记录见 [使用指南](USAGE.md) 与 [质量筛选验收](TESTING_QUALITY.md)。kitchen 和 Giannini-Hall 已下载并检查图片可解码，尚未完成本计划的正式重建对照。

准备面试时，重点能解释：SfM 如何为 MVS/3DGS 提供相机与初始化、内参与位姿的区别、原始匹配和几何验证的区别，以及为何不同路线需要不同评价指标。
